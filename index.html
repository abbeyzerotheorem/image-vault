GitHub Backend Setup

Store your images in a GitHub repository - Free, permanent, and accessible anywhere!

  1. Create a GitHub account if you don't have one (free)
  2. Create a new repository (name it anything, e.g., "image-storage")
  3. Generate a Personal Access Token:
    • Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
    • Click "Generate new token" → "Generate new token (classic)"
    • Give it a name (e.g., "Image Storage")
    • Select these scopes: repo, workflow
    • Click "Generate token" and COPY IT IMMEDIATELY (you won't see it again)
  4. Enter your details below:

Security Note: Your token is stored only in your browser's localStorage. It never leaves your computer. GitHub limits: 100GB storage, 1GB max file size (free).
